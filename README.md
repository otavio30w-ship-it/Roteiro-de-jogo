# Jogo de Adivinhação de Palavras

Projeto desenvolvido como atividade de encerramento da disciplina **Desenvolvimento de Aplicações Web I** (IFPB — Campus Campina Grande, 2026).

## Funcionalidades
* Escolha aleatória de palavras com dicas temáticas.
* Exibição dinâmica das letras descobertas e tentativas restantes.
* Bloqueio de letras repetidas e caracteres inválidos.
* Suporte ao envio de letras pressionando a tecla `Enter`.
* Contador de vitórias e derrotas na sessão.

## Tecnologias Utilizadas
* **HTML5** (estrutura semântica)
* **CSS3** (Flexbox e responsividade)
* **JavaScript** (manipulação do DOM, eventos, arrays e estruturas de repetição)

## Como jogar
Acesse o link publicado via GitHub Pages na seção *About* deste repositório, digite uma letra por vez e tente descobrir a palavra antes que as 6 tentativas acabem.
